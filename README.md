# 🏦 NexusPay

**El banco digital para emprendedores latinoamericanos.**

NexusPay es un ecosistema financiero digital que integra cuenta, pagos, ahorro, inversión, seguros, gestión empresarial y análisis financiero en una sola aplicación. Diseñado específicamente para emprendedores digitales que hoy quedan fuera del sistema bancario tradicional.

---

## 🎯 Propuesta de valor

Nuestro producto estrella es **NexusCredit**, un módulo de microcréditos con inteligencia artificial que analiza el flujo de caja digital del solicitante en lugar de exigir un historial crediticio tradicional.

- ⚡ Aprobación en menos de 24 horas
- 💰 Montos hasta $5.000.000 COP
- 📊 Score calculado en segundos con IA
- 📈 Tasas desde 8% anual

## 🛠️ Stack tecnológico

| Capa | Tecnología |

| Backend | Supabase |

| Autenticación | Supabase Auth |

| Gráficos | Chart.js |
| Generación de PDF | jsPDF |
| Hosting | Vercel |

---

## 🔐 Seguridad

- **Row Level Security** en base de datos: cada usuario solo accede a sus propios datos
- **Autenticación JWT** con Supabase Auth
- **Cifrado TLS/HTTPS** en todas las comunicaciones
- **Verificación biométrica facial** con IA
- **Códigos de retiro únicos** de un solo uso
- **Cumplimiento** con Ley 1581, Ley 1266, Ley 1273, SARLAFT y Circular Externa 052 SFC
